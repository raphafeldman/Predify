# Expo SDK 54 (rebaixado de propósito)

Este projeto foi rebaixado do SDK 57 para o SDK 54 porque, em julho de 2026, o
Expo Go publicado na App Store da Apple ainda não suporta o SDK 57 (atraso na
revisão da Apple). SDK 54 é a versão mais recente com suporte garantido tanto
na App Store quanto na Play Store.

Antes de escrever código, confira a documentação da versão exata em
https://docs.expo.dev/versions/v54.0.0/ — não assuma que as convenções da v57
se aplicam aqui.

Não atualize para uma versão mais nova sem antes confirmar que o Expo Go da
App Store já suporta o SDK em questão (veja https://expo.dev/changelog).
